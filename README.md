Title: 
Algorithm Search

Description:
This project is to demonstrate how algorithm find its way to solve a maze. The algorithm involve are Breadth First Seacrh (BFS), Depth First Search (DFS), Greedy Algorithm, and A* Search Algorithm. The result show that A* Search Algprithm produce the fastest execution time in searching the Goal State starting from the Start State.

Features:
Path visualisation

Technologies used:
Python

How to run the project:
1. Create a new folder in Visual Studio
2. Instal Live Server extension. This is to run the visual page
3. Save all the files and HTML file in one folder
4. Click run on HTML file
5. A page that demonstrate the algorithm search will execute.
